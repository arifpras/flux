================================================================================

All analysis files follow the pattern:

Examples:
├── 20260122_last_5days_analysis.py       - Python script
├── 20260122_last_5days_output.txt        - Text output
├── 20260122_SWING_SIGNALS_REPORT.txt     - Report document
└── 20260122_validate_realtime.sh         - Shell script

Benefits:
✅ Chronological sorting
✅ Easy to identify analysis date
✅ Clear purpose from filename
✅ No confusion between different date's analyses
