## Signal Strength Interpretation

### Multi-Scale Alignment
Wavelet signals are generated by analyzing price movements across **three different timeframe scales**:

1. **Short-term (High Frequency - Scale ~8)**: Day-to-day movements, entry/exit timing
2. **Medium-term (Mid Frequency - Scale ~16)**: 3-5 day trends, momentum confirmation
3. **Long-term (Low Frequency - Scale ~24)**: Weekly trends, directional bias

### Signal Meanings
- **STRONG BUY** (Alignment 3/3): All three timeframes show bullish signals → Highest confidence
- **BUY** (Alignment 2/3): Two timeframes aligned → Moderate confidence
- **NEUTRAL** (Alignment 1/3): Only one timeframe bullish → Weak signal
- **SELL** (Alignment 0/3): No timeframes aligned bullish → Bearish

## Wavelet Method Advantages for Trading

✅ **Multi-timeframe Analysis**: Capture signals across hourly, daily, weekly, monthly patterns

✅ **Trend Localization**: Identify when trends start and end (unlike Fourier which averages)

✅ **Denoising**: Distinguish real price moves from market noise

✅ **Breakout Detection**: Wavelets excel at identifying sharp market regime changes

✅ **Volatility Estimation**: Different wavelet scales isolate volatility at different timeframes

## Implementation Details

### Wavelet Choice
- **Morlet Wavelet** (Complex wavelet)
- **Advantages**: 
  - Best for analyzing oscillatory behavior in financial markets
  - Natural frequency interpretation
  - Excellent for identifying cycles and reversals
  - Commonly used in professional trading systems

### Analysis Parameters
- **Scales**: 1-31 (covers ~1 to 32-day periodicities)
- **Normalization**: Min-max scaling (0-1) for scale-independent analysis
- **Decomposition Levels**: 3 (captures sub-daily, daily, and multi-day patterns)

### Signal Generation Logic
```
For each bar:
  - Get wavelet coefficient at short-scale (high frequency)
  - Get wavelet coefficient at medium-scale (middle frequency)
  - Get wavelet coefficient at long-scale (low frequency)
  
  If all 3 > threshold: STRONG BUY (alignment 3/3)
  If 2 > threshold: BUY (alignment 2/3)
  If 1 > threshold: NEUTRAL (alignment 1/3)
  If 0 > threshold: SELL (alignment 0/3)
```

## Statistical Foundation

✅ **Parseval's Theorem**: Wavelet energy = original signal energy (no information loss)

✅ **Scale-to-Frequency Mapping**: Wavelet scale inversely relates to frequency

✅ **Time-Frequency Localization**: Wavelets maintain both time and frequency information (unlike Fourier)

✅ **Continuous Decomposition**: Overlapping scales provide smooth transitions between timeframes
