ROOT CAUSE ANALYSIS
================================================================================

HOW THE ERRORS OCCURRED:

The source data (idx_dividend_history.csv) contains individual payment records,
each with a dividend_amount. When analyzing annual dividend, the correct 
approach is:

CORRECT METHOD (what was done):
  Sum all payments in year Y → Calculate 3-year average → Yield = Avg / Price

ERRONEOUS METHOD (what apparently happened earlier):
  Sum all 3 years of data → Calculate weighted avg → MISTAKENLY treat sum as annual
  
Example - BMRI:
  Correct:    2025: 466, 2024: 354, 2023: 529 → Avg: 450 → Yield: 8.2% ✓
  Incorrect:  Total 3 years: 1,349 → Wrongly claimed: ~1,449 → Yield: 26.4% ✗

This is a COMMON analytical error in dividend analysis - confusing accumulated
vs annual metrics. The corrected document now uses the proper methodology.
